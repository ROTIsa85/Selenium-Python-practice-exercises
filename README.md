# Selenium Python Practice Exercises

This repository contains hands-on Selenium WebDriver + Python exercises I've been
building while transitioning from manual/black-box QA testing into web UI test
automation.

## Background

I'm a QA Test Analyst with 15+ years of experience in manual/black-box software
testing, including test planning, execution, and defect tracking for point-of-sale
(POS) systems. I'm currently expanding into automated web testing using Python and
Selenium WebDriver.

## What's in this repository

Practice scripts covering core automation concepts, including:
- Browser setup and navigation
- Locating and interacting with page elements
- Explicit and implicit waits
- Login flow testing (valid and invalid cases)
- Checkboxes, radio buttons, and dropdown menus
- Logout / session handling
